# The art

Every duck, egg and pond is painted with ChatGPT image generation, then checked and finished by `scripts/duck.py` and
`scripts/import_art.py`, which put the finished pictures in `web/ducks/`.

- `ducks/`: each duck's finished picture, one per duck
- `ducks.json`: the list of ducks: names, kanji, colors, one-line descriptions and outfits
- `chatgpt-prompts.md`: the prompts, for remaking any of it
- `originals/`: ChatGPT's duck pictures as they came
- `incoming/`: the eggs, ponds, ripples, decorations and icon, as they came
- `sheets/`: the very first duck sheets
- `reference.png`: the reference sheet a new duck is drawn to match
- `lofi.txt`: the lofi playlist
